## 📌 Projetos em destaque

### 💬 [Alfa CV Maker](https://github.com/AlexAlvesAmorim/alfa-cv-maker) — ![CI](https://github.com/AlexAlvesAmorim/alfa-cv-maker/actions/workflows/ci.yml/badge.svg)
